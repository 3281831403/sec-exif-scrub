用户上传的照片发到公网后，拍摄地点的经纬度还能被直接读出来：段解析只读第一段，第二段元数据未处理；段长度按大端解析，小端图整体错位；定位元数据用固定偏移，图片带其他段时找错位置；剔除字段后不重写偏移，解析器读到悬空指针；缩略图删除后不清理偏移表，仍指向原数据；残留校验只查标签名不查实际坐标值；残留校验用子串匹配，正常文本被误判；批量处理复用段列表，后一张图沿用前一张图的结构；策略校验不检查未处理缩略图；输出不校验整体长度，截断后文件损坏。scrub/exif.py 是核心，tests/test_exif.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

运行方式
--------
在仓库根目录执行：

    python -m pytest tests -q

当前基线为 15 failed，且没有 error。测试期只依赖 pytest，运行过程不联网。
